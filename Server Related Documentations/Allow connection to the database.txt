✅ 1.Allow connection to the database:
GRANT CONNECT ON DATABASE pioneer_alpha_website_db TO pioneer_alpha_website_db_user;


✅ 2.Make the user the owner (recommended & easiest):
ALTER DATABASE pioneer_alpha_website_db OWNER TO pioneer_alpha_website_db_user;


✅ 3.Give schema-level permissions (public schema):
GRANT USAGE, CREATE ON SCHEMA public TO pioneer_alpha_website_db_user;

✅ 4.Grant full access to existing tables & sequences:
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO pioneer_alpha_website_db_user;
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO pioneer_alpha_website_db_user;

✅ 5.Auto-grant privileges for future tables
ALTER DEFAULT PRIVILEGES IN SCHEMA public
GRANT ALL PRIVILEGES ON TABLES TO pioneer_alpha_website_db_user;

ALTER DEFAULT PRIVILEGES IN SCHEMA public
GRANT ALL PRIVILEGES ON SEQUENCES TO pioneer_alpha_website_db_user;
